## 1. Features Implemented & Changes

### 1.1 3-Option AI Assistance Mode Toggle (Card B Recommendation Editor)
- **Component**: `src/components/Dashboard.jsx`
- **UI Selector**: Added segmented control with `role="radiogroup"` offering 3 modes:
  1. **Manual** (`#mode-manual-btn`): Assessor writes ATEX mitigation recommendations from scratch. Disables footer AI Draft trigger button; zero background Gemini calls are made.
  2. **Suggestions** (`#mode-suggestions-btn`, **Default**): Assessor receives AI-suggested recommendations displayed as an unpersisted draft inside `#ai-draft-container`.
  3. **AI Agent** (`#mode-agent-btn`): Disabled stub with DOM `disabled={true}`, `"Coming soon"` badge/tooltip, and pointer-events disabled.
- **Assessor Preference Persistence**: User selection persists in `localStorage` under `hitec_ai_recommendation_mode` and defaults to `'suggestions'`.

### 1.2 Safety Guardrail: Draft-then-Approve Enforcement
- **Pending Draft Container**: Rendered only in Suggestions mode when a draft exists (`#ai-draft-container`). Contains an editable draft textarea (`#ai-draft-textarea`), **Accept** button (`#accept-draft-btn`), and **Dismiss** button (`#dismiss-draft-btn`).
- **Zero Auto-Persist**: Under no circumstance does AI generation overwrite active report state or Firestore photo records until the assessor explicitly clicks **Accept**.
- **Footer Draft Trigger**: Updated sticky right footer with Draft Rec button (`#footer-generate-btn`) and live Assistance Mode indicator.

### 1.3 Security Hardening (`isMockMode`)
- **File**: `src/firebase.js`
- **Fix**: Removed all runtime URL query parameters (`?mock=true`, `?test=true`) and localStorage sniffing from `isMockMode`. Mock mode is now strictly governed by build-time environment flags (`import.meta.env.VITE_ENABLE_TEST_MOCK === "true"`), preventing any unauthorized mock-state spoofing on production builds.
